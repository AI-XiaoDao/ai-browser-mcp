# 🚀 小白使用指南（零基础 3 分钟上手）

> 不用懂编程。你只需要会**双击**和**说话**。

---

## 第一步：双击运行（10 秒）

1. 解压下载的压缩包
2. 双击 **AI-Fbowser-Mcp.exe**
3. 屏幕上出现一个小窗口，显示「AI浏览器 MCP Server v3.0.0 — 正在启动 MCP 服务...」

> 💡 **MCP 服务全自动**：双击后一切自动完成（初始化浏览器 → 启动服务 → 创建首个浏览器），无需任何手动操作。
>
> 💡 **关闭浏览器窗口 = 退出程序**：点右上角 X 会退出整个程序；保持运行请最小化黑色控制台窗口。
> 这样 AI 随时能用浏览器干活。
>
> 💡 **懒人模式**：如果你已经配置好 Cursor，连双击都可以省——Cursor 打开时若发现服务没运行，会**自动帮你启动 exe**（环境变量 `AI_BROWSER_AUTO_START=0` 可关闭此行为）。
>
> 🔴 **怎么彻底退出**：在 Cursor 里说「关闭AI浏览器」（会调用 browser_shutdown 命令），或在任务管理器结束进程。

## 第二步：让 Cursor 认识它（1 分钟）

**方式 A（推荐，本仓库用户）**：仓库已自带 `.cursor/mcp.json` 配置，用 Cursor 打开本仓库 → 重启 Cursor 即可自动加载。

**方式 B（任意项目）**：打开 Cursor 设置 → MCP → 添加服务器，填入：

```json
{
  "mcpServers": {
    "ai-browser": {
      "command": "node",
      "args": ["D:/你的解压路径/mcp_bridge.js"],
      "env": {
        "AI_BROWSER_MCP_HTTP_POST": "http://127.0.0.1:9222/mcp"
      }
    }
  }
}
```

保存后**重启 Cursor**。看到 Cursor 里出现 `browser_navigate`、`browser_snapshot` 等工具就是成功了。

> 自检命令（可选）：`node mcp_bridge.js --check` → 显示「成功 | 版本 3.0.0」

## 第三步：用大白话指挥浏览器

在 Cursor 对话框直接说（**不要写代码**）：

| 你想干什么 | 就这么说 |
|-----------|---------|
| 打开网页 | 「打开百度首页」 |
| 看页面上有什么 | 「告诉我这个页面上有哪些按钮和输入框」 |
| 按文字点按钮 | 「点击『登录』按钮」 |
| 填表 | 「用户名填 test，密码填 123456」 |
| 采集数据 | 「把商品列表的标题和价格整理成表格」 |
| 截图 | 「截个图给我看看」 |
| 等页面加载完 | 「等页面加载完再操作」 |
| 看最近发生了啥 | 「最近浏览器里发生了什么事件」 |

AI 会自动组合 `browser_navigate` / `browser_snapshot` / `browser_click_text` / `browser_fill_form` / `browser_screenshot` / `browser_event` 等 255 个工具完成任务。

## 常见问题

**Q: 怎么知道程序在运行？**
A: 浏览器打开 http://127.0.0.1:9222/health ，显示 `"status":"ok"` 就是在运行；或看控制台窗口是否还在。

**Q: Cursor 里看不到工具？**
A: 配置后必须**完全重启 Cursor**（不是重开对话）。

**Q: 提示连接失败？**
A: 确认 AI-Fbowser-Mcp.exe 在运行（控制台窗口在），再试。

**Q: 会连网泄露数据吗？**
A: 不会。MCP 服务只监听本机 `127.0.0.1:9222`，数据不出电脑。
